Hexagon Escape
A fast-paced arcade survival game built with Godot 4 and GDScript.

#Overview
Hexagon Escape is a reflex-based game where the player controls a sprite using the WASD keys and must survive inside a shrinking hexagon.

As the hexagon continuously shrinks toward the center, only one of its six sides contains an escape opening. The player must quickly locate and move through the correct exit before touching any of the other five sides.

Touching a closed side results in an immediate game over.

#Features
WASD player movement
Continuously shrinking hexagon obstacle
Randomized exit side
Collision detection system
Game Over mechanics
Increasing challenge based on reaction speed

#Technologies Used
Godot 4
GDScript

#Objective
Survive as long as possible by escaping through the open side of each shrinking hexagon.

#Controls
Key	Action
W	-Move Up
A	-Move Left
S	-Move Down
D	-Move Right
